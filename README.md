Stats Calculator for Inazuma eleven Go Light

I made it for my IEGORandomizer, You need the ie_a.fa there is one made up from 10 7z but you can made a new randomized run with my IEGORandomizer on the profile.

required Python 3.8+:

    python StatCalcIEGO1.py ie_a.fa
    python StatCalcIEGO1.py --cli ie_a.fa

DO NOT DELETE calibracion.json AND KEEP IT in the same directory as the program. If you upload the save of the game(game.ie4) which you can get from Checkpoint app calibracion.json will change after reading if your players
has been trained. The calc use the train curves, element and the game data.

To upload the training use «Import Training...» on the window or option 6 on cli, selecting the game.ie4 that you have exported from Checkpoint. No equipment or passives are included in the calculated stats; the app detects if the player have equipment or trained equipt and adverts you.
